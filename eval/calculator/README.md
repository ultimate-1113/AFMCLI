# AFM 3 Core Advanced から関数電卓を呼ぶ

Swift の `LanguageModelSession` に関数電卓を1つ登録すると、AFM は式を引数にしてアプリのコードを呼び出せる。6つの確定式を日本語の同じ指示で渡すと、使用を促さなくても6問すべてでツールを1回呼び出した。Rust が返した値は6問とも正しかった。Framework の呼び出し引数とコールバックの式、返した値と履歴に届いたツール出力が6件すべて一致した。[実機の全12セッション](native-paired.jsonl)・[Apple のツール呼び出しの仕様](https://developer.apple.com/documentation/foundationmodels/expanding-generation-with-tool-calling)

| 確定式6問の条件 | 数値だけで正答 | 時間の中央値 |
|---|---:|---:|
| Swiftで電卓を登録せずにAFMが最終回答 | 0/6 | 約0.24秒 |
| Swiftで電卓を登録し、AFMが最終回答 | 5/6 | 約0.78秒 |
| 同じ登録あり6問のコールバックが返した値 | 6/6 | 要求処理開始から値到着まで約0.57秒 |
| 式を直接RustのCLIへ渡す | 6/6 | 約0.002秒 |

表のSwift最終回答とRust CLIの所要時間にはプロセス起動を含む。コールバックの時刻はSwift内の時計で、計測はその後もAFMの最終回答まで続けた。登録ありの1問ではツールが `7146` を返し、AFMの最終文は「結果は 7146 です。」となった。計算結果の意味は6/6で正しく、指定の形式を守った最終文は5/6だった。入力中の式をそのまま計算する6問に限った数値である。試行は各条件1回。従来の `fm` 直接回答も同じ6問で0/6、ツールの使用を明示したSwiftの補助2問は2/2だった。[確定式・採点規則](probe.py)・[CLIの生出力](direct.jsonl)・[Rustの生出力](native-formulas.jsonl)・[明示指示の2問](native-explicit.jsonl)

## 確定式から数値を取り出す

```sh
afmcli --text calc '739 * 418 - 267 * 593 + 18^3 - 764'
# 155639
afmcli --text calc '((7/12 + 5/18) / (11/9 - 2/3))^2'
# 2.4025
afmcli --text calc --angle deg '12 * sin(30) + sqrt(144) - log10(1000)'
# 15
```

`calc` は式を標準入力、引数、または `-i` から受け取る。通常のJSON出力には式、`value`、近似の有無、角度単位が入る。`--text` は確定式の数値と改行だけを返す。四則・整数べき・組み合わせは表現可能な範囲で有理数として計算するため、例えば `0.1+0.2` はちょうど `0.3` になる。結果が循環小数なら既約分数を返す。三角関数・対数などの一般の値には浮動小数点を使い、JSONに `approximate: true` を付ける。角度は標準でラジアン、`--angle deg` で度に切り替わる。

利用できる主な式は `+ - * / ^ !`、括弧、`abs sqrt ln log10 exp`、三角関数と逆三角関数、双曲線関数、`nCr nPr`、`pi e`。式の長さは4,096バイト、字句512個、入れ子48段まで。ゼロ除算、定義域外、数値範囲外はエラーになる。固定シードの547件をPython標準ライブラリの分数演算・数学関数で照合し、有効な535件と不正な式12件がすべて期待どおりだった。浮動小数点の許容誤差は絶対・相対とも `1e-12`。この照合でのモデル呼び出しは0回。[独立した照合コード](check_math.py)・[実行記録](math-run.json)

## 文章から式を提案する

自然文の読み取りと演算を分担させる設計は、PALの「モデルが計算手順を表し、外部の処理系が計算する」という考え方を参考にした。この実装は受け取れる入力を関数電卓の文法に限定し、各試験でRustが実際に評価した式を保存する。[PAL論文](https://proceedings.mlr.press/v202/gao23f.html)・[著者の実装](https://github.com/reasoning-machines/pal)

```sh
printf '%s\n' 'ノートは1冊275円です。18冊の代金と注文全体の送料320円を合計してください。' |
  afmcli calc --from-text
```

確定式を認識できればその場で計算する。文章を渡すとAFMに式を作らせ、Rustで構文と計算の成否を調べる。文章から得た式には `status: review` を付け、実行した式と値を一緒に返す。今回、ラベルの注文では `18*275 + 320` から5,270円を得た。一方、2,800円から25%値引きした後に10%課税する問では、提案式が税額を間違えて2,408円を返した。正解は2,310円。計算が成功したことと、数量の関係を正しく読み取ったことは個別に確認できる。[文章題の定義](word_problems.py)・[式と実測値](words.jsonl)

## 再実行

```sh
cargo build --release --locked
python3 -B eval/calculator/check_math.py --binary target/release/afmcli
python3 -B eval/calculator/verify.py
```

Swiftの実機比較には対象モデルが使えるmacOSが必要。検証用プログラムは公開APIでツールを登録し、モデルが実際に選んだ式を記録する。角度単位はホストが固定し、電卓には式だけを渡す。各回の採点はツールが返した短い値とAFMの最終回答にそれぞれ行う。途中式だけを計算する場合もあるため、コールバックの最後の値が常に依頼の答えとは限らない。[Swiftのビルド・実行方法](native/README.md)・[TXT・JSON・CSVの入出力例](../../examples/file_tasks/README.md)
